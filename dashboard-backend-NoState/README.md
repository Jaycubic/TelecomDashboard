# Call Quality Dashboard Backend

Express + PostgreSQL API for the Voice Call Quality Reviews dashboard.

## Main endpoints

- `GET /health`
- `GET /api/kpis`
- `GET /api/state-quality`
- `GET /api/state-quality/confidence`
- `GET /api/indoor-outdoor`
- `GET /api/trend`
- `GET /api/filters/options`
- `GET /api/map/india`

All analytical endpoints accept the existing filter query parameters where applicable: `state`, `year_start`, `year_end`, `operator`, `region`, and `inout`.

## Location catalogue

The filter catalogue contains the current 28 Indian states and 8 union territories. Dataset spelling variants are translated to canonical location names for filtering and map joins.

## Map source

`/api/map/india` proxies a pinned India state/UT TopoJSON snapshot. The frontend has a bundled fallback so a map-source fetch failure does not prevent the dashboard from rendering its analytical data.

## Data calculations

- Average rating = mean of the source `rating` field for selected records.
- Call Drop Rate = `Call Dropped` records / selected records × 100.
- Voice Degradation Rate = `Poor Voice Quality` records / selected records × 100.
- Satisfactory call rate = `Satisfactory` records / records in the relevant period or Indoor/Outdoor setting × 100.

No new observations are generated by the API.
